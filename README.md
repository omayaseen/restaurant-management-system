# 🍽️ Restaurant Management System

A web-based Restaurant Management System developed using Django. This application allows customers to browse the menu, place orders, and view order history, while staff and administrators can efficiently manage restaurant operations.

---

## 🚀 Features

### Customer
- User Registration & Login
- Browse Menu
- Add Items to Cart
- Place Orders
- View Order History

### Staff
- Manage Customer Orders
- Update Order Status

### Admin
- Add, Edit & Delete Menu Items
- Manage Users
- View All Orders
- Dashboard

---

## 🛠️ Tech Stack

- Python
- Django
- HTML
- CSS
- Bootstrap
- SQLite

## ⚙️ Installation

```bash
git clone https://github.com/omayaseen/restaurant-management-system.git

cd restaurant-management-system

python -m venv venv

source venv/bin/activate      # Mac/Linux

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver
```
